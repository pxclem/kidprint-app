# 🎨 KidPrint IA

KidPrint est une application web (Jamstack) permettant aux parents de générer et d'imprimer des carnets d'activités sur-mesure pour leurs enfants, avec l'aide d'une IA.

## Fonctionnalités
- 🤖 **Assistant IA** : Recommandation d'activités en langage naturel.
- 📚 **PDF Bundler** : Sélection de plusieurs fiches pour générer un cahier personnalisé.
- 🖨️ **Impression optimisée A4** : Marges et sauts de pages parfaits pour les imprimantes.
- ❤️ **Système de Favoris** : Sauvegarde locale (Offline-first).

## Déploiement (Netlify)
Ce projet est configuré pour être déployé en un clic sur Netlify grâce au fichier `netlify.toml` et utilise des Netlify Functions (Node.js) pour le backend serverless.
