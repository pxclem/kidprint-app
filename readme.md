# 🎨 KidPrint IA

Application web Jamstack pour générer, trier et imprimer des cahiers d'activités sur-mesure pour enfants au format A4.

## Démarrage local

1. Ouvre un terminal dans le dossier du projet.
2. Lance `npm start`.
3. Ouvre `http://localhost:8888` dans ton navigateur.

## Tests

- `npm test` pour exécuter les tests existants.

## Profils

- Crée un nouveau profil depuis l’interface pour enregistrer un ensemble distinct d’activités.
- Chaque profil conserve son propre historique de recherche, ses favoris et sa sélection d’impression.
- Le profil actif est chargé automatiquement à l’ouverture de l’application.

## Notes

- Les données sont stockées côté client dans `localStorage`.
